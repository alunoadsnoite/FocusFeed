# Privacidade

FocusFeed não possui backend, analytics, publicidade, login ou coleta remota.
A versão Android release não solicita acesso à Internet.

Acesso ao uso permite identificar o app em primeiro plano para aplicar bloqueio
à seleção feita pelo usuário. O serviço não lê o conteúdo das telas.
A seleção, saldo, histórico e sessão são guardados localmente. No iOS, a seleção
usa tokens opacos do Screen Time e um App Group local para as extensões.

O usuário pode parar o monitor, revogar permissões e excluir os dados do aplicativo.
Backup/restauração do próprio sistema operacional pode incluir os dados locais.
Dados excluídos não podem ser recuperados por um servidor do FocusFeed.
